# Contributing to ChatCLI

Thanks for your interest in contributing! 🎉

## Getting Started

```bash
# Clone the repo
git clone https://github.com/2663402852/chatcli.git
cd chatcli

# Install dependencies
npm install

# Run in dev mode
npm run dev
```

## Development

- **Language**: TypeScript + React (Ink)
- **Build**: `npm run build`
- **Lint**: `npm run lint`

## How to Contribute

### Reporting Bugs

- Open an issue with a clear title and description
- Include steps to reproduce, expected vs actual behavior
- Mention your OS, Node.js version, and terminal

### Suggesting Features

- Open an issue with the `enhancement` label
- Describe the use case and why it matters

### Pull Requests

1. Fork the repo
2. Create a feature branch: `git checkout -b feat/my-feature`
3. Make your changes
4. Run `npm run lint` to check types
5. Commit with [conventional commits](https://www.conventionalcommits.org/):
   - `feat: add new feature`
   - `fix: resolve bug`
   - `docs: update documentation`
   - `chore: maintenance tasks`
6. Push and open a PR

### Code Style

- Use TypeScript strict mode
- Follow existing patterns in the codebase
- Keep components small and focused
- Add JSDoc comments for public APIs
